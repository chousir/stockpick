# 11 — ProPicks 風格全清單分析（Phase 1 手動流程）

> 本檔是「跑完 `make week GROUP=abc/def` 後，怎麼產出 ProPicks 風格進場
> 清單」的標準流程。手動把資料丟給 Claude Opus，**零代碼成本**。
>
> Phase 2（自動化為 `make picks`）等本流程穩定後再做。

---

## 為何做這一步

`group_analysis.md` Section 5「推薦個股深度分析優先順序」只是**機械排名前 10**
（5 日漲幅 + 族群強度），缺：

- **為何入選**的具體理由
- **進場思路**（價位、訊號、停損）
- **主要風險**
- **訊號交集判讀**（D∩E、E∩F 等）
- **居安思危**訊號（看似穩定但暗藏風險的族群）
- **異常崛起**個股（top 10 機械排名外、但有 setup 的票）

這一步把全週篩選結果丟給 Claude Opus，讓 AI 在**完整候選宇宙**中挑，
不被 top 10 框住。

## 流程

### Step A：取得 4 份輸入檔

跑完 `make week GROUP=def`（或 `=abc`）後：

```
reports/YYYY-Www/
  ├─ group_analysis.md               ← 族群脈絡
  ├─ screen_result_d_quality_leader.csv    ← D 全部入選
  ├─ screen_result_e_growth_momentum.csv   ← E 全部入選
  └─ screen_result_f_value_rebound.csv     ← F 全部入選
```

（跑 GROUP=abc 則對應 a/b/c 三個 CSV）

### Step B：開 Claude Opus 對話

到 [claude.ai](https://claude.ai)，選 **Claude Opus**（最強模型，這步值得用）。

### Step C：依序貼入 4 份檔案內容

順序：先 prompt → 再 group_analysis.md → 再 3 個 CSV。

### Step D：等 Claude 回覆，存到本週目錄

Claude 出來的 Markdown 存到：

```
reports/YYYY-Www/picks.md
```

## Prompt 範本（複製整段貼到 Claude Opus）

```
請扮演 Investing.com ProPicks AI 的台股策略分析師，依本週篩選結果產出
進場清單。

## 你會看到的資料

1. group_analysis.md：族群強度、入選分布、推薦清單（Section 5 為機械
   排名前 10、Section 6 為前 4 大領漲族群完整名單）。Section 2/3/6 已含
   **5 日中位、上漲家數(breadth)、法人買超家數比、每檔法人(張，近 20 日三大法人淨買賣超)**。
2. screen_result_*_*.csv：每組策略的「全部入選股」原始 CSV

> 注意：CSV 是「全部入選」（每組可能 30-100 檔），
> group_analysis.md 是「彙整與排名」。
> **請以 CSV 為「候選宇宙」，group_analysis.md 為「族群脈絡」**。

## 任務

### 1. 進場清單（5-7 檔）

從**所有 CSV 入選股**中挑 5-7 檔最佳候選。**重要原則**：

- Section 5 top 10 只是機械排名（5 日漲幅 + 族群強度），**不要被它框住**
- 主動挑出 Section 5 沒列、但你判斷有 setup 的個股：
  - **逆勢佈局**：族群弱但個股強（族群輪動候選）
  - **低基期反轉**：5 日漲幅平或負、但基本面好且策略多重命中
  - **主升段補強**：已啟動但還沒衝過頭、有跟漲空間
  - **危險期黑馬**：大盤偏弱時逆勢上漲的（外資/法人布局訊號）
- 三策略命中（D+E+F）或雙策略命中（D∩E、E∩F、D∩F）優先

每檔給：

| 欄位 | 說明 |
|---|---|
| 次產業/概念 | 該檔實際次產業或概念（如 CPO、被動元件、晶圓代工、鏡頭、網通、電信），非 TWSE 大分類 |
| 為何入選 | 一句話：命中策略 + 族群定位 + 動能/估值/品質 + 法人(張)籌碼方向 |
| 進場思路 | 明確：價位區間、訊號條件、停損位 |
| 主要風險 | 一句話（如漲多但法人賣超、量縮、估值偏高）|

### 2. 訊號交集（如本週有）

- **D ∩ E（品質 + 成長）**：雙引擎候選
- **E ∩ F（成長 + 低估）**：戴維斯雙擊候選
- **D ∩ F（品質 + 低估）**：巴菲特風格核心持股
- **D ∩ E ∩ F（全命中）**：本週最強訊號

每個交集列入選股 + 為什麼是強訊號（一句話）。

### 3. 本週市場節奏（一段話）

- 哪族群在領、哪族群落後；**用次產業視角**看輪動（例：光電業是鏡頭強還是 AOI 設備強；通信網路是 CPO/網通強還是電信防禦盤強）
- 整體市場強弱判讀（多頭 / 盤整 / 震盪 / 偏空）
- **居安思危訊號**：看似穩定但暗藏風險的族群
  （例：5 日中位為正但上漲家數低＝單檔灌水；領漲股「法人(張)」為負＝漲多但法人賣超；高動能但量縮；估值已偏高的領漲股）
- **異常崛起**：看似冷門但本週開始發力的族群或個股
  （CSV 入選但 Section 5 沒列到的；或族群弱但法人逆勢買超的個股）

### 4. 觀察名單（3-5 檔，非進場）

不選但值得追蹤的，每檔一行：股號 + 名稱 + 觀察點
（如「等突破 MA60」「等 Q3 財報」「等族群輪動到此」）。

## 規則

- **不下單一結論，多空並陳**
- 不給目標價、不寫「強烈建議」「飆股」「保證」「絕對」
- 數字必須來自附帶資料，不要自己編
- 風險段不可比進場理由短
- 繁體中文，台股術語

開始分析。
```

## 為什麼不只看 top 10？

`group_analysis.md` Section 5 的 top 10 公式：

```
分數 = 0.5 × 5 日漲幅 + 0.25 × 成交金額 + 0.15 × 法人 + 0.1 × 策略數
```

**這個公式偏向「已啟動」的票**。漏掉：

| 情境 | 公式為何漏 | 但可能是好標的 |
|---|---|---|
| 逆勢佈局 | 5 日漲幅不夠強 | 族群輪動時的下一棒 |
| 低基期反轉 | 5 日漲幅低 | 策略多重命中 + 估值便宜 = 戴維斯雙擊候選 |
| 主升段休息 | 短期漲幅暫緩 | 半山腰拉回布局點 |
| 危險期黑馬 | 整體市場弱拉低 sigmoid 分母 | 逆勢資金布局訊號 |

**居安思危**的核心：危險期大家都跌時，少數逆勢上漲的標的常常是下一個
領漲。Top 10 機械排名抓不到這種 setup，需要 AI 用全清單去看才能挑出來。

D/E/F 篩選本身（hard filter）已經把 1800 檔濾到 ~30-100 檔（每組），
**這個 universe 才是 Claude 該看的全貌**，而非 top 10 的窄窗。
