## 0. 一句話目標

找出「**法人資金已流入、但股價尚未明顯反映**」的個股候選——使用者口中的「CP 值股」，
也就是**補漲機會**。全程用**回測驗證哪個因子組合最有領先力**，產出的是
「**把勝率疊高的觀察清單**」，**不是預測、不是明牌、不給目標價**（守 `CLAUDE.md` Part 3.5）。

「做完」的定義（success criteria，總綱）：
- 能回答「**本週哪些個股**符合『錢進來了、價格還貼著低點』」，且用的因子是回測選出來的、不是拍腦袋。
- 能回答「這份清單的歷史**領先力（lift / 領先天數）**有多少」，並誠實標出統計力限制。
- 之後能再疊「**相對便宜**」這層（PE 相對自身歷史 / 次產業中位數）。
- 全程可離線重跑（吃本地快取），不打 Goodinfo、不違反任何限速。

## 1. 為什麼做、跟 docs/12 / Tide 的差異

### 1.1 Tide 泡泡圖的洞察與盲點
| | Tide 泡泡圖 | 我們現在的 sector_rotation（docs/12） |
|---|---|---|
| X 軸 | **5 日**法人淨流（億） | **20 日**法人淨流 |
| Y 軸 | **資金加速度**（億/天） | **價格位階**（距 60 日低點 %） |
| 泡泡大小 | 20 日累計淨流 | —（表格欄位） |
| 正規化 | 無（原始「億」金額，大族群恆大） | 每族群自身 60 日 **z 分數**（跨族群可比） |
| 價格資訊 | **完全沒有** | 有（Y 軸） |

- Tide 的「資金加速度」**我們早就在算**——`rotation.py` 的 `flow_momentum`（短窗淨額 − 前一短窗），
  報表「動能(張)」欄就是它。Tide 的貢獻不是新指標，是**把加速度放上座標軸**這個擺法。
- Tide 三條軸**全是資金、沒有價格**。而「錢進來、價格還沒動」這件事（CP 值核心）
  剛好藏在它沒畫的那條軸上。**這就是本研究要補的洞。**

### 1.2 回測數據：先破除「20 日太長 / 5 日太晚」的直覺
來源 [research/rotation/calibration_20260611.md](../research/rotation/calibration_20260611.md)
（1 年、34 個族群起漲點、隨機基率 7.3%、lift = 命中率/基率）：

| 訊號 | lift | recall | 中位領先 |
|---|---|---|---|
| trust_flow_20d (z>1.0) | **1.50** | 44% | 8 日 |
| flow_breadth_20d (>0.6) | **1.53** | 29% | 7 日 |
| trust_flow_5d (z>1.0) | 1.10 | 47% | 10 日 |
| foreign_flow_5d (z>1.0) | **0.91** | 59% | — |
| flow_momentum（純加速度, z>0.5） | **1.05**（≈隨機） | 97% | 8 日 |

結論（族群層、樣本有限）：
1. **20 日窗預測力高於 5 日窗**（1.5 vs 1.1），且中位領先 8 個交易日——走在起漲前面，不是落後。
2. **純加速度單獨用 ≈ 隨機**。它高 recall、貼基率精度，當「進場訊號」沒用。
3. 但加速度有 20 日流沒有的用途：**當「新鮮度濾鏡」**——區分「新鮮流入」vs「流入已久（來不及）」。
   這正是使用者「下次看到已經太晚」痛點的正解。

→ 設計取向：**20 日流當主訊號，加速度當新鮮度濾鏡，兩者各司其職。不為追快把主軸換成 5 日。**

⚠️ **統計力但書**：34 樣本 / 1 年，lift 1.5 與 1.3 的差距可能只是雜訊。下面所有結論都要 walk-forward
驗證，不把單次回測數字當聖經。**現實天花板大概就是 lift 1.3–1.5**（疊高勝率，不是水晶球）。

## 2. 核心概念：CP 分數與它的致命歧義

「錢進來、價格沒動 = 補漲空間大」寫成可計算的分數：

```
CP 分數 ≈ 資金流入強度（z 分數）  ÷  價格已反映程度（距低點 % / 距均線 %）
         分子大、分母小 = CP 高
```

⚠️ **必須先釘死的歧義**——「錢一直進、價不動」有兩種**相反**解釋，光看比值無法分辨：
- **(A) 吸籌打底**：主力低檔默默吃貨還沒拉 → 真補漲（要的）。
- **(B) 賣壓沉重**：買盤一直被倒貨吃掉、價格上不去 → 接刀（要避的）。

分辨靠第三維度：**加速度方向**（A 常伴流入加速；B 是流入減速卻價跌）、**breadth**（A 族群普遍進；
B 常個股孤軍）、**量價**（B 常放量下殺）。→ 這就是為何要做**多因子**、不只做單一比值排名。

## 3. 獵物 label（核心兩種＋選配反轉，分開比）

回測的「起漲事件」沿用 docs/12 的 R2 邏輯，但在個股層**同時建多種 label，各跑一張 lift 表**，
比較哪種因子組合對哪種獵物最有效。使用者選定**核心兩種都標、分開比**；
**Label-3（反轉）為選配**——B2 試標、由 lift 裁決去留（過不了門檻即剔除，不降低標準）：

| | **Label-1：未起漲前（埋伏）** | **Label-2：剛起漲小幅（追突破）** | **Label-3：超跌反轉（選配）** |
|---|---|---|---|
| 前置 | 低基期、無顯著前期流出 | 剛離低點 | **長期重流出（退潮）＋ 深跌** |
| 條件 | 低基期（距 N 日低 ≤ 容忍%）＋ 前瞻 K 日漲 ≥ X% | 剛離低點小幅起漲（+3~8%）＋ 資金同步放大 ＋ 前瞻續漲 | 前期 L 日累計大幅流出 ＋ **加速度由極負急轉正／單日流入 >> 短窗均** ＋ 前瞻反彈 ≥ X% |
| 抓的時點 | 起漲**前**（價貼低點） | 起漲**初**（剛突破） | 跌勢**轉折點**（V 底起手） |
| 主訊號窗 | 20 日（lift 1.5、領先 8 日，**夠用**） | 5 日 | **加速度／單日**（20 日太慢，會錯過轉折） |
| 預期特性 | 命中率較低、領先較久、要忍盤整 | 命中率較高、領先較短、追高風險較大 | **三種中確定性最低**；「真反轉」與「逃命反彈（接刀）」當下難分 |
| 對應 CP 值 | 原教旨 CP（錢進、完全沒動） | 放寬 CP（剛動一點、追初升段） | 反向 CP（深跌後資金急轉，賭均值回歸） |

> **Label-3 的及格門檻（嚴守，否則不上線）**：
> （1）回測 lift 須與核心兩種同級（~≥1.3），否則剔除——加它**不放寬標準**；
> （2）必須量**訊號之後**的前瞻報酬與**中位領先天數**：若訊號與噴出同日（領先 0 天）＝抓不到、不可交易；
> （3）需**確認**才算觸發（如連 2 日續買 / breadth 同步轉正），不接受單日資金 spike 就進——單日 flip 接刀率最高。
> A2 的「加速度新鮮度標」套到**左側流出象限**即天然的反轉偵測器（同源、近乎免費）。

> X / K / N / L / 容忍% 的實際數值：個股波動大於族群（族群 X=10%），個股可能要 X=15~20%。
> 確切值在 B2 milestone 用資料試掃、不在此寫死，全部進 `settings.yaml`（守 `CLAUDE.md` 2.3）。

## 4. 分階段 milestone（A → B → C 按序）

### Phase A — 族群圖重組（不新資料，先確認方向對不對）

**A1 — 連續 CP 分數**
- 目標：在 rotation table 加 `cp_score` 欄（資金 z ÷ 價格位階），報表新增「CP 候選」排名區塊。
- 用什麼資料：純現有 `rotation.py` 特徵，無新資料、無新依賴。
- 產出：`sector_rotation.md` 多一段 CP 候選 Top-N；CSV 多 `cp_score` 欄。
- 驗收：`make rotation`（或對應 CLI）→ 看新區塊；既有測試全綠。
- 限制：仍是**族群層**——告訴你「哪個族群」，不是「哪檔股」。

**A2 — 加速度新鮮度標**
- 目標：把 `flow_momentum` 轉成「**加速中 / 放緩中**」標籤，把「主升續勢」象限細分為
  新鮮（加速、CP 仍在）vs 退潮（放緩、來不及）。
- 副產品：同一標籤套到**冷卻象限**（流出 × **低位階**）＝**反轉偵測器**雛形——
  深跌族群若加速度轉正（流出收斂），即 Label-3 超跌反轉的族群層前哨（§3）。
  注意：出貨警訊（流出 × **已漲**）momentum 轉正只是「出貨趨緩」，非超跌反轉，不掛此標。
- 產出：報表象限區塊與 CP 候選標註新鮮度；解「下次看到已太晚」痛點。
- 驗收：報表標籤正確對應 `flow_momentum` 正負；測試補 happy path。

### Phase B — 個股 CP 分數 + 回測（核心，真正的肉）

**B1 — 個股特徵面板**
- 目標：從現有日線 + 法人快取，建 `(date, stock_id) → 特徵` 長表。
- 特徵（每檔每日）：資金（5/20 日淨流 z、加速度、外資/投信拆分）、價格位階（距 60 日低、
  距 20/60/240 均線 %）、相對強度（個股 vs 大盤 / 所屬次產業）、量能（周轉率 z）。
- 資料覆蓋：**個股層只在上市乾淨**（日線＋法人全覆蓋）；上櫃日線僅候選股、有缺口，
  研究**先框在上市**，覆蓋率寫進產出 meta。
- 產出：純資料層模組 + 測試（離線 fixture，不打外部）。
- 驗收：對已知幾檔手算特徵對得起來；測試綠。

**B2 — 多 label + 個股版 event study**
- 目標：把 R2 回測 harness 下沉到個股層；標 Label-1 / Label-2（核心）＋ Label-3（反轉，選配），各跑訊號掃描。
- 產出：**每種 label 一張 lift 表**，列各因子組合的 lift / recall / 中位領先 / F1；
  寫進 `research/cp_value/`（本地，比照 `research/rotation/`）。
- Label-3 裁決：須過 §3 三條及格門檻（lift ≥~1.3、領先 > 0 天、需確認非單日 spike），否則剔除不上線。
- 方法誠實底線：walk-forward / 留出樣本、報觸發數與信賴感、明標統計力限制（反轉事件更稀少、力更弱）。
- 驗收：`make` 某指令 → 重現各表；結論寫成 calibration md。

**B3 — 個股 CP 候選清單**
- 目標：用 B2 勝出的因子組合，產**本週個股 CP 候選**。
- 產出：候選 CSV + 報表區塊（每檔標：所屬次產業象限、資金 z、加速度新鮮度、位階、命中哪種 label 型態）。
- 驗收：清單可離線重跑；與庫存/觀察/本週命中疊圖（沿用 docs/12 §5.4 參與度邏輯）。
- 限制：這是**觀察清單**，個股持有決策仍需個股層籌碼/基本面判讀（守人設「多空並陳、由人決策」）。

### Phase C — 估值層（PE 相對位階）

**C1 — 個股 PE + 相對位階**
- 目標：trailing EPS → 個股 PE；算 PE 相對**自身 1~3 年歷史百分位** + **次產業 trailing PE 中位數**。
- ⚠️ **資料現實**：使用者要的「次產業**預估** PE」需分析師**前瞻 EPS 估值**——**無資料源、不瞎掰**。
  能做的是 **trailing / 歷史百分位**，產出明標「**相對便宜（trailing）**，非前瞻估值」。
- 驗收：幾檔 PE 與公開資料對得起來；缺 EPS 的明標「未取得」不補零。
- > **升級註記（2026-06-14）**：C1 起初以單季 EPS×4 年化**代理** PE（commit 8b81184），後升級為
  > **官方日 trailing PE/PBR/殖利率**（TWSE `BWIBBU_d` ＋ TPEX `peratio`，commit a3e2508）——真 trailing、
  > 虧損股以官方 PB 補、上市+上櫃覆蓋。**自身 1~3 年歷史百分位**待官方日 ratios 累積數月（本期僅當日橫斷面）。
  > 詳見 `docs/02` §「官方日估值比 BWIBBU」。

**C2 — CP × 估值三重濾網**
- 目標：合併「錢進來（B）＋ 沒漲（B）＋ 相對便宜（C1）」→ 終版候選清單。
- 產出：候選清單加估值欄與三重濾網標記。
- 驗收：濾網邏輯可追溯；報表區塊完整。

### Phase D — 多窗起漲偵測（M-MH）｜Phase 2 校準裁決

> milestone 全文見 [docs/08-milestones.md](08-milestones.md) M-MH 段。
> 動機：2501 國建實證「20 日資金窗被舊賣單稀釋、短窗(外資 3/5d)早 ~1 週翻正」，
> 想用多窗 + 背離因子早抓起漲。Phase 1 已把面板多窗化（窗集合 [1,3,5,10,20]＋
> `flow_decel`/`price_flow_div` 背離因子，commit 6afeac3）。

**Phase 2 校準（2026-06-17，1374 檔上市 × 250 日、三 label）裁決＝中止條件成立、不改線上判讀。**

GATE 改判「早偵測力」（短窗中位領先 20d-z ≥2 日 ＋ 早閘子集 lift > 基率），三 label 全 ❌：

| 訊號（L1 埋伏，N 可比） | 觸發 | lift | 跨窗配對中位領先 vs 20d |
|---|---|---|---|
| `foreign_flow_20d_z +low`（現任冠軍） | 5984 | **1.67** | — |
| `net_flow_5d_z +early+low`（減量後短窗） | 5283 | **1.64** | 1 日（~50% coin flip）|
| `foreign_flow_5d_z +early`（無價貼低） | 7358 | 1.29 | 1 日 |

1. **減量沒讓短窗贏**：樣本數拉到可比後，gated 短窗 lift 1.62–1.64 ≈ 20d 的 1.67（打平）。
   觀測到的 lift 2.0+ 是 tiny-N（6/43）雜訊。`+early` 拿掉 `+low` lift 掉到 1.19–1.30 →
   **lift 是「價貼低」在做工，20d 早就吃到了，早閘本身沒加值。**
2. **短窗無系統性領先 20d**：跨窗配對領先中位 0–1 日、約 50% coin flip。2501 那種「短窗早一週」
   是真的，但落在尾巴、不是中位。
3. **唯一真發現＝`short_only` ~30%**：約三成起漲事件，短窗抓到法人進場、但 20d-z 在事件前 30 日
   從未達標（20d 結構漏掉、只有短窗看得到，2501 屬此尾巴）。**短窗的價值不是「更早」，是
   「額外覆蓋 20d 看不到的那群」。**

→ 設計裁定：**沿用 §1.2 取向——20 日流當主訊號、不為追快換成短窗**。多窗鏡頭與背離因子留在面板
（Phase 1 純加法、向後相容），校準軌新增多窗掃描＋跨窗配對領先指標＋早閘變體（research 軌、
不碰生產）。「距低 >15 硬擋」**不動**。Phase 3（趨勢分級取代硬擋）原設計前提＝短窗有領先力，
此前提未成立故**不照原樣做**；若要救 `short_only` 覆蓋，限「額外低信心觀察欄」非取代（待使用者拍板）。

⚠️ **統計力但書**：1 年單一樣本，每季資料累積後重跑 `make cp-value-calib` 重校；不把單次數字當聖經。

## 5. 與現有架構的銜接（不重造輪子）

- **回測引擎**：B2 直接沿用 docs/12 R2 的 event-study 框架（起漲定義、lift、領先、z 視窗、walk-forward），
  只是把宇宙從「次產業籃子」換成「個股」、label 從一種變兩種。
- **資料**：全吃 `data/cache/`（日線 `daily_*` / `stock_day_*`、法人 `institutional_*`、EPS）。不新增資料源。
- **設定**：所有門檻（X/K/N、CP 分數權重、PE 百分位界線）進 `config/settings.yaml`，不寫死。
- **次產業分類**：沿用 `config/concepts.yaml`（未標股的資金/估值方向「無法判讀」，不硬塞）。
- **新依賴**：預期**不需要**。若 B 階段覺得要（如建模庫），**先問**。
