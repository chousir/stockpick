## 3. 預先登記的四個因子（一個定義、方向寫死；價格一律用原始收盤）

交易日位移以「日線快取的全市場交易日曆」計數（≥300 檔有價之日）；任何窗內缺日或出現價格不連續
（相鄰兩筆收盤 |報酬| > 15%）→ 該因子 null（不補值）。

| # | 欄名 | 定義 | 方向 | 依據（事前） |
|---|---|---|---|---|
| F1 | `mom_6_1`（個股 RS） | close[t−21] / close[t−126] − 1（6 個月報酬、跳過最近 1 個月） | **＋** | 產業內動能（Asness–Porter–Stevens 2000）；跳過近月避開短期反轉。族群內排名等價「個股 vs 族群」相對強弱 |
| F2 | `high52_near`（52 週高點接近度） | close[t] / max(close[t−249..t]) | **＋** | George–Hwang（2004）；docs/08 原列「recency」，本輪以接近度為正式定義，recency 不另測（避免多重比較） |
| F3 | `eps_accel`（EPS 加速） | [(E_q − E_{q−4}) − (E_{q−1} − E_{q−5})] / P_q | **＋** | He–Narayanamoorthy（2020）盈餘加速度 |
| F4 | `rev_accel`（月營收 YoY 加速） | YoY3(m) − YoY3(m−3)；YoY3(m)＝(R_m+R_{m−1}+R_{m−2}) / (前一年同三個月) − 1 | **＋** | 台股月營收高頻基本面；3 個月和降春節錯月雜訊 |

- **F3 point-in-time**：E＝FinMind 單季 EPS（`financials_*.parquet`，docs/02 已對帳＝MOPS 單季）；
  q＝t 當日**已過保守期限**之最新季——一般業法定期限（季後 45 日：5/15、8/14、11/14；年報翌年 3/31）
  再加緩衝，Q1–Q3 一律延至 5/30、8/31、11/29（涵蓋金融業等較晚期限；寧可舊、不可前視），Q4 取 3/31；
  逾期申報個案未處理（照列偏誤）；P_q＝季末最後交易日收盤；
  E_q、E_{q−1}、E_{q−4}、E_{q−5} 任一缺、或 P_q ≤ 0 → null。
- **F4 point-in-time**：R＝FinMind 月營收（`month_revenue_*.parquet`）；m＝t 當日已過公告期限
  （次月 10 日，即 t ≥ m 次月 11 日）之最新營收月；需 m−17…m 連續 18 個月；任一分母 ≤ 0 → null。
- **覆蓋底線**：因子在主宇宙（過 gate、target 非 null 的股週）非 null 比例 < 70% → 該因子「不可判（覆蓋不足）」。
  預期 F2 因 250 日回看自 2022-06 起才有值。

## 4. 量尺與裁決判準（跑前寫死）

**target**＝面板 `r20`（entry＝次一交易日收盤、exit＝其後第 20 個交易日；未到期／下市＝null）。
前瞻窗（entry 之後至 exit）內出現價格不連續 → target null。族群內比較等價於用 alpha20
（同日市場基準對組內每檔相同）。

### 4.1 三個量尺

- **M1 族群內 IC（主量尺）**：每週，對所有合格組算組內置中百分位排名
  `c = (rank − (n_g+1)/2) / n_g`（tie 取平均排名）；`IC_週 = Pearson(c_因子, c_r20)`，跨該週全部組的成員合算
  （＝產業中性 rank IC）；該週合格成員 < 10 → 該週不計。報週序列平均＋moving-block bootstrap CI
  （block＝ceil(20/5)+1＝5 週、B=1000、seed=42；`factor_lab.moving_block_bootstrap_ci`）。
- **M2 首選超額（實用量尺）**：每組挑因子最高者（tie → 成交額大 → stock_id 小），
  `超額 = r20(首選) − 組內 r20 平均`；週內跨組平均 → 週序列平均＋同法 CI。
- **M3 對現行規則**：同組內以現行規則選一檔（偏好帶距離小 → 成交額大 → stock_id 小，即
  `shortlist._RANK_KEYS` 在同次產業內的效果），`差 = r20(因子首選) − r20(現行首選)`（同一檔＝0）；
  週序列平均＋同法 CI。

### 4.2 「成立」五條件（全過才算；主宇宙、r+20、預註冊方向）

- **C1 效應量**：M1 週 IC 平均 ≥ +0.03（docs/22 §0 效應量底線）。
- **C2 顯著**：M1 bootstrap CI95 下界 > 0（docs/23 §1(b)）。
- **C3 分段一致**：週 IC 序列依時間切 5 段等長連續子期間（無參數訓練，故不留訓練段），
  段內平均 > 0 的段數 ≥ 4/5（docs/23 §1(a) 比例門檻）。
- **C4 跨 regime**：以快照日 `regime` 切片（進攻／中性／防禦），各切片週 IC 平均＋CI；切片週數 < 30 標
  「樣本不足」不進分母；`factor_lab.regime_alignment_verdict` 須為「跨 regime 穩健」（≥2 個可判切片與全樣本同號，docs/23 §1(c)）。
- **C5 實用一致**：M2 平均 > 0 **且** M3 平均 > 0（點估計；兩者 CI 照列）。M2/M3 單檔抽樣雜訊遠大於 M1，
  其 CI 不當門檻（事前估計：真 IC 0.05 時 M2 z≈1.3），只要求方向一致——避免「IC 顯著但實際挑出來的那檔不贏」。

### 4.3 裁決五選一

1. **成立**：C1–C5 全過，**且** Bonferroni 校正（k＝4 個因子、α=0.0125 → 同一 bootstrap 分布的
   0.625%／99.375% 分位）CI 下界 > 0。
2. **候補（多重比較邊緣）**：C1–C5 全過，但 Bonferroni CI 跨 0 → 不提生產提案，累積樣本後重驗。
3. **未過關**：週 IC 平均 > 0 但 C1–C5 任一不過（照列哪條不過）。
4. **無證據**：週 IC 平均 ≤ 0 且未達反向顯著。
5. **反向顯著**：週 IC 平均 ≤ −0.03 且 CI95 上界 < 0——照實記錄，**不得事後翻轉方向當成立**
   （docs/23 §3 規則；若要測反向，另立預註冊）。

- 覆蓋不足（§3）或可計週數 < 100 → 「不可判」，不進上述五選一。
- 多個「成立」：提案用 M1 週 IC 平均最高者；**不建 composite**（docs/22 WS-F 開賽門檻「個股層存活 ≥3」）。
- 零個「成立」：照實記錄否證／未過關，因子名單寫入 memory（playbook/20 §6.6），shortlist 維持現行規則。

### 6.2 回答本輪問題

**在 shortlist 會入選的強族群內，四個預註冊因子沒有一個能穩定挑出 r+20 較佳的那一檔；因子首選對現行規則首選的差（M3）
四個都在 ±0.13% 內、CI 全跨 0——沒有證據支持替換現行決勝規則。** 依 §4.3：零個「成立」→ shortlist 維持現行規則、零生產改動；
`bear_hints` 固定首項「族群層訊號、個股層未驗證」仍屬實。

用詞分寸：F2／F3／F4 是「未過關」不是「已否證」。點估計為正、但都低於預註冊效應量底線 0.03（C1）——這是**本面板**的讀數，
點估計本身有抽樣誤差：F2／F4 距 0.03 約 0.4–0.5 個標準誤（F3 約 1.1），CI95 上界 0.042–0.054 **並未排除 0.03–0.05 的小效應**；
第二意見粗估本設計對真 IC≈0.035 判「成立」的檢定力約 2 成（未校準）——**零個成立排除的是 ≳0.055 的大效應，對 0.03–0.05 量級只是弱證據**。
F1 方向與預註冊相反、未達反向顯著＝無證據。F2 的 M2 CI95 下界僅 +0.03%（同一重抽分布的 Bonferroni 下界 −0.06%，且依 §4.2 M2 的 CI
