  因子 tie → 成交額大 → stock_id 小）。`band_dist` 在帶內＝0，會有大量同值（tie 取平均排名，同 M-Pick2）。
- **H2 各裁決的意義**（避免事後解讀漂移）：

| `band_dist` 裁決 | 意義 |
|---|---|
| 成立 | C1–C5 全過且 Bonferroni 下界 > 0：族群內越貼近偏好帶 r+20 越差 → 提案「族群內決勝拿掉偏好帶鍵」（跨族群排序另議） |
| 候補 | 同方向，多重比較邊緣 → 不提案，累積樣本 |

| 反向顯著 | 程式判的是 `band_dist` 週 IC 平均 ≤ −0.03 且 CI95 上界 < 0，等價於 `neg_band_dist` IC ≥ +0.03 且 CI95 下界 > 0：偏好帶鍵在族群內有顯著**正向**資訊 → 照實記錄，不得事後翻轉當成立 |
| 不可判 | 覆蓋 < 70% 或可計週數 < 100 → 不裁決 |

## 4. 量尺與裁決判準（跑前寫死；程式沿用 `intra_pick.evaluate_factor`／`classify`，零改動）

**量尺**（定義同 docs/32 §4.1）：target＝`r20`（§2.4）。M1＝每週產業中性 rank IC（組內置中排名 `c＝(rank−(n_g+1)/2)/n_g`，跨組合算；
該週合格成員 < 10 不計），週序列平均＋moving-block bootstrap CI（block＝5 週、B＝1000、seed＝42）；
M2＝因子首選（tie → 成交額大 → stock_id 小）− 組內 r20 平均；M3＝因子首選 − 現行首選（偏好帶距離小 → 成交額大 → stock_id 小）。

**「成立」五條件**（主宇宙、r+20、預註冊方向＋；全過才算）：

| 條件 | 判準 |
|---|---|
| C1 效應量 | M1 週 IC 平均 ≥ +0.03 |
| C2 顯著 | M1 bootstrap CI95 下界 > 0 |
| C3 分段一致 | 「可計週」的週 IC 序列（通過 §2.2 週合格成員 ≥ 10 者）依時間 5 等分，段內平均 > 0 的段數 ≥ 4 |
| C4 跨 regime | 週 IC 序列依快照 `regime` 欄（逐快照日一個標籤）切片（進攻／中性／防禦）；**切片週數＝落在該 regime 的可計週數**（不是 361 週快照；< 30 標「樣本不足」不進分母）→ `regime_alignment_verdict`＝「跨 regime 穩健」（≥ 2 個可判切片與全樣本同號），且全樣本平均 > 0 |
| C5 實用一致 | M2 平均 > 0 **且** M3 平均 > 0（點估計；CI 照列不當門檻，docs/32 §4.2） |

**裁決五選一**（§4.3，同 docs/32）：**成立**＝C1–C5 全過**且**該族 Bonferroni CI 下界 > 0；**候補**＝C1–C5 全過但 Bonferroni CI 跨 0；
**未過關**＝週 IC 平均 > 0 但 C1–C5 任一不過（照列哪條）；**無證據**＝週 IC 平均 ≤ 0 且未達反向顯著；
**反向顯著**＝週 IC 平均 ≤ −0.03 且 CI95 上界 < 0。**不可判**＝覆蓋 < 70% 或可計週數 < 100。

**與 docs/32 判準不同處（量尺與裁決層面僅此四點；樣本與資料差異見 §2）**：(a) target 是除權息還原總報酬（§2.4）；(b) **Bonferroni 分族**：主族 k＝2、副族 k＝2，
α＝0.05/2＝0.025，取同一重抽分布的 1.25%／98.75% 分位；實作＝逐假設呼叫 `evaluate_factor` 前把 `IntraPickConfig.n_tests` 覆寫成該族的 k
（settings `backtest.intra_pick_holdout.n_tests_primary`／`n_tests_secondary`；`backtest.intra_pick.n_tests: 4` 是 M-Pick2 的值，不動）；(c) H2 用鏡像因子（§3）；(d) regime 為降級定義（§2.4）。
（新增的數字只有 k＝2 與 §2.3 的日期，兩者都是規則性設定，不含對極端值敏感的統計量——對照 playbook/90 2026-09-29「事前寫的判準，先推導其統計量對極端值的敏感度再定門檻」自查。）

**裁決後續**：H1 或 H2「成立」→ 附 shortlist 決勝鍵改動**提案 diff 草稿（不套用）**，交使用者 F1 裁決；兩者皆成立各自提案、不建 composite。
副族 F2／F4「成立」或「候補」→ 只記為複驗結果，不提生產提案（其改動需另立提案流程）。零個成立 → 照實記錄，因子名單寫入 memory
（playbook/20 §6.6），shortlist 維持現行規則。反向顯著 → 照實記錄，不得事後翻轉方向。

**預期（事前寫下，非門檻；未校準）**：週 IC 平均標準誤約 0.013（docs/33 §2A）；真 IC＝0.03 時 C1＋C2 同時過約 5 成、0.04 約 8 成，
再疊 C3–C5 會打折；H1 有贏家詛咒，真值可能只有 0.02–0.035；H2 在 M-Pick2 的點估計僅 −0.017、低於 C1 底線，預期「未過關」或「無證據」。
**樣本外跑出「未過關」是很可能的結局**，屆時只能說「沒有足夠證據」，不能說「已否證」。
